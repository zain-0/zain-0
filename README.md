- **[Energy Sphere](https://github.com/zain-0/ai-vs-human)** — a WebGPU-first volumetric effect built with Three.js and TypeScript, with WebGL2 fallback, adaptive quality tiers, visual regression tests, and performance budgets.
- **[Khidmaat backend](https://github.com/zain-0/khidmaat-backend)** — backend engineering in Go for the Khidmaat project.
- **[ASL Model](https://github.com/zain-0/ASL-Model)** — a Python-based machine-learning project for American Sign Language.
- **[Instance Segmentation with YOLO](https://github.com/zain-0/Instance-Segmentation-Using-YOLO)** — applied computer vision using modern object-detection workflows.
